# Role Registry

Purpose:
Lightweight role-guidance layer for UniApp v2.

This file defines:

* role positioning priorities
* recruiter expectations
* keyword direction
* success signals
* role boundaries
* optimization emphasis

This is NOT a resume content file.
Do not duplicate resume bullets, projects, or achievement libraries here.

Architecture Role:
Knowledge Base + Role Registry + Active Resume Set + Discovery Resume → Resume Variant Generation

Guiding Principles:

* prioritize JD relevance
* preserve role purity
* optimize recruiter readability
* optimize ATS relevance naturally
* avoid keyword stuffing
* avoid cross-role contamination
* prioritize credibility over completeness

* refinement guidance
