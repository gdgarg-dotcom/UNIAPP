\# UniAppSys



Structured strategic resume architecture for benchmark-aligned resume generation, optimization, and retrieval.



\## Architecture



01\_Knowledge\_Base → Reusable strategic evidence and positioning assets



02\_Benchmarks → Canonical role benchmark definitions



03\_Masters → Benchmark-aligned master resumes



04\_Variants → Strategically differentiated resume variants



05\_Project\_Configs → System prompts, workflows, configs, and operational instructions



\---



\## System Flow



Knowledge Base → Benchmarks → Masters → Variants



\---



\## Design Principles



\* Low entropy architecture

\* Benchmark purity

\* Strategic reuse

\* Minimal duplication

\* Retrieval-friendly structure

\* LLM-optimized organization

\* Semantic consistency



\---



\## Folder Purpose



\### 01\_Knowledge\_Base



Reusable:



\* achievements

\* executive summaries

\* positioning narratives

\* keywords

\* projects

\* tools

\* writing standards



\### 02\_Benchmarks



Defines:



\* target role ecosystems

\* strategic positioning

\* benchmark expectations

\* role boundaries



\### 03\_Masters



Canonical benchmark-aligned resumes built from:



\* benchmarks

\* knowledge base assets



Used as:



\* primary strategic retrieval layer

\* source for future variants



\### 04\_Variants



Strategically differentiated resume variants aligned to benchmark ecosystems.



Only preserve:



\* meaningful positioning differences

\* reusable strategic value

\* low-overlap variants



\### 05\_Project\_Configs



Operational system layer containing:



\* prompts

\* workflows

\* audit logic

\* generation instructions

\* system architecture references



\---



\## Operational Rules



\* Maintain strict benchmark alignment.

\* Avoid duplicate variants.

\* Remove weak or regenerable resume variants.

\* Preserve only strategically reusable assets.

\* Do not create unnecessary folders or abstraction layers.

\* Keep architecture semantically stable and low entropy.
