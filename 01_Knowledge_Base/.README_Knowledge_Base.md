\# Knowledge Base



Purpose:



Central reusable factual and positioning intelligence layer for UniApp.



This folder contains reusable modular assets used to support:



\* resume optimization

\* ATS alignment

\* recruiter positioning

\* JD customization

\* resume variant generation



Core Components:



\* Achievement Library

\* Executive Profile Library

\* Executive Summary Library

\* Positioning Library

\* Project Library

\* Keyword Library

\* Tool Library

\* Role Alignment Map

\* Writing Style Guide

\* Positioning Guardrails



Rules:



\* Do not store role-specific resume variants here.

\* Keep content reusable, role-flexible, and JD-adaptable.

\* Maintain low duplication and semantic clarity.

\* Preserve factual consistency across reusable assets.

\* Prioritize reusable strategic evidence over highly contextual wording.

\* Use Knowledge Base assets selectively to strengthen:



&#x20; \* achievements

&#x20; \* positioning

&#x20; \* metrics

&#x20; \* tools

&#x20; \* summaries

&#x20; \* strategic proof points

&#x20; \* ATS relevance

\* Prioritize JD relevance over completeness.

\* Prefer concise, evidence-supported enrichment.

\* Do not force unrelated content into resumes.

\* Do not introduce unsupported claims or positioning.



Runtime Usage Guidance:

Knowledge Base assets act as modular enrichment sources.



Use them to:



\* strengthen resume variants

\* improve ATS alignment

\* reinforce recruiter relevance

\* enrich positioning selectively

\* improve keyword alignment naturally



Do not use them to:



\* override JD relevance

\* force unrelated positioning

\* create keyword stuffing

\* inject generic content

\* duplicate Discovery Resume content unnecessarily



Architecture Flow:



Knowledge Base + Role Registry + Active Resume Set + Discovery Resume → Resume Variant Generation
