\# Knowledge Base



Purpose:

Central strategic evidence and positioning repository for UniAppSys.



This folder contains reusable canonical assets used across:



\* Benchmarks

\* Master Resumes

\* Resume Variants



Core Components:



\* Achievement Library

\* Executive Profile Library

\* Executive Summary Library

\* Positioning Library

\* Project Library

\* Keyword Library

\* Tool Library

\* Role Alignment Map

\* Tag Taxonomy

\* Writing Style Guide



Rules:



\* Do not store role-specific resume variants here.

\* Keep content reusable and benchmark-agnostic.

\* Maintain low duplication and semantic clarity.

\* Preserve semantic stability across reusable strategic assets.

\* Treat this folder as the canonical strategic evidence layer.

\* Prioritize reusable strategic evidence over highly contextual resume language.

\* Use Knowledge Base assets to support the refinement and evolution of benchmark-aligned master resumes.

\* Incorporate Knowledge Base assets selectively into Masters as new achievements, projects, metrics, positioning signals, tools, or strategic capabilities emerge.



Architecture Flow:

Knowledge Base → Benchmarks → Masters → Variants
